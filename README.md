# #borrow a book

**วัตถุประสงค์**
-เพื่ออำนวยความสะดวกในการยืมและคืนหนังสือ 
-เพื่อช่วยค้นหาหนังสือและตรวจสอบสถานะหนังสือ 
-เพื่อลดความยุ่งยากในการจัดการข้อมูลการยืม-คืนหนังสือ 
-เพื่อพัฒนาระบบที่ใช้งานง่าย 

**กลุ่มลูกค้า**
-นักเรียน,นักศึกษา,อาจารย์,ร้านให้ยืมหนังสือ

**ฟังก์ชั่น**
-ค้นหาและยืมหนังสือ
-จัดการหนังสือที่ยืม

**เป้าหมายของระบบ**
-สามารถค้นหาและยืมหนังสือได้ง่ายและรวดเร็ว
